## Install the W4Studica extension

Click a screenshot to view it at full size.

1. Open the [W4Studica VS Code Extension releases](https://github.com/W4Studica/W4Studica-VS-Code-Extension/releases) and download the latest `.vsix` file from the release **Assets**.

    [![W4Studica VS Code Extension release page showing the VSIX asset](../../../assets/vscode-extension-release.png)](../../../assets/vscode-extension-release.png)

2. In WPILib VS Code, click the **Extensions** icon in the Activity Bar. The screenshot shows the pointer on that icon.

    [![WPILib VS Code Extensions icon with the mouse pointer over it](../../../assets/vscode-extensions-icon-zoom.png)](../../../assets/vscode-extensions-icon-zoom.png)

3. Select **…** in the Extensions view, then choose **Install from VSIX…**.

    [![The Extensions menu with Install from VSIX highlighted and the mouse pointer visible](../../../assets/vscode-install-menu-zoom.png)](../../../assets/vscode-install-menu-zoom.png)

4. Select the `.vsix` file you downloaded and click **Install**.

    [![The downloaded vmxpi-wsr VSIX selected in the file picker](../../../assets/vscode-file-picker-zoom.png)](../../../assets/vscode-file-picker-zoom.png)

Continue to [Adding W4Studica Libraries](adding-w4studica-libraries.md) to create a C++ robot project and configure it for VMX-Pi.
