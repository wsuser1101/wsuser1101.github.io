---
title: VMX-Pi 네트워크
---

VMX Robot Manager는 W4Studica와 같은 명령 이름을 유지하면서 NetworkManager로 네트워크를 설정합니다. VMX on WPI 이미지에는 개발 컴퓨터가 로봇에 직접 연결해 로컬로 배포할 수 있도록 Wi-Fi 핫스팟을 미리 구성할 예정입니다. 유선 이더넷은 자동 구성됩니다. 핫스팟을 변경하거나 다시 만들 때는 `setupHotspot`을 사용하세요.

## Wi-Fi 액세스 포인트

팀 번호가 1234라면 다음 명령으로 `VMX-1234` 핫스팟을 만들고 로봇 주소를 `10.12.34.2`로 설정합니다.

```sh
sudo setupHotspot VMX 1234 2.4 password
```

마지막 값은 WPA2 비밀번호이며 8~63자여야 합니다. 예시 비밀번호를 그대로 사용하지 말고 변경하세요. 2.4 GHz 또는 5 GHz를 선택할 수 있습니다. 현지 5 GHz 채널 규정을 모르면 2.4 GHz를 사용하는 편이 안전합니다. 채널은 명령 중 물어볼 때 선택하거나 `--channel N`으로 지정할 수 있습니다.

저장된 핫스팟을 다시 켜려면 다음을 실행합니다.

```sh
sudo toggleNetMode ap
```

## 유선 이더넷

로봇은 유선 인터페이스에서 `172.22.11.2/24`를 사용하고 직접 연결한 컴퓨터에 DHCP 주소를 제공합니다. 컴퓨터의 유선 IPv4 설정을 자동/DHCP로 바꾸세요. 프로필을 수동으로 다시 설정하려면 다음을 실행합니다.

```sh
sudo setupEthernet
```

SSH로 로봇에 접속합니다.

```sh
ssh ubuntu@172.22.11.2
```

## Wi-Fi 공유기에 연결

VMX-pi와 개발 컴퓨터를 같은 공유기에 연결하려면 공유기 SSID와 비밀번호를 입력합니다.

```sh
sudo toggleNetMode wifi HomeRouter RouterPassword
```

이전에 저장한 Wi-Fi 프로필을 사용하려면 인수 없이 `sudo toggleNetMode wifi`를 실행합니다. 공유기가 로봇 주소를 할당하므로 DHCP 임대 목록에서 주소를 확인하세요. 네트워크가 바뀌면 현재 SSH 연결이 끊길 수 있습니다. 새 프로필이 활성화된 뒤 다시 접속하세요.

핫스팟 주소는 `10.TE.AM.2` 형식입니다(예: 팀 1234는 `10.12.34.2`). 유선 주소는 `172.22.11.2`로 유지됩니다.
