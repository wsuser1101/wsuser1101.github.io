## W4Studica 확장 프로그램 설치

캡처를 클릭하면 원본 크기로 볼 수 있습니다.

1. [W4Studica VS Code Extension 릴리스 페이지](https://github.com/W4Studica/W4Studica-VS-Code-Extension/releases)를 열고 최신 릴리스의 **Assets**에서 `.vsix` 파일을 다운로드합니다.

    [![VSIX 파일이 표시된 W4Studica VS Code Extension 릴리스 페이지](/assets/w4studica/vscode-extension-release.png)](/assets/w4studica/vscode-extension-release.png)

2. WPILib VS Code의 Activity Bar에서 **Extensions** 아이콘을 클릭합니다. 아래 캡처에서 마우스 포인터가 해당 아이콘을 가리킵니다.

    [![마우스 포인터가 올라간 WPILib VS Code Extensions 아이콘](/assets/w4studica/vscode-extensions-icon-zoom.png)](/assets/w4studica/vscode-extensions-icon-zoom.png)

3. Extensions 화면에서 `…`를 누른 다음 `Install from VSIX…`를 선택합니다.

    [![Extensions 메뉴에서 Install from VSIX를 선택하는 화면과 마우스 포인터 확대](/assets/w4studica/vscode-install-menu-zoom.png)](/assets/w4studica/vscode-install-menu-zoom.png)

4. 다운로드한 `.vsix` 파일을 선택하고 **Install**을 누릅니다.

    [![파일 선택 창에서 다운로드한 vmxpi-wsr VSIX를 선택한 모습](/assets/w4studica/vscode-file-picker-zoom.png)](/assets/w4studica/vscode-file-picker-zoom.png)

[W4Studica 라이브러리 추가](adding-w4studica-libraries.md)에서 C++ 로봇 프로젝트를 만들고 VMX-Pi 라이브러리를 설정하세요.
