# VMX on WPI

**Studica VMX-pi에서 WPILib 2026을 사용하세요.** 이 프로젝트는 VMX-pi HAL, GradleRIO 배포 대상, VS Code 확장 프로그램과 64비트 Ubuntu용 로봇 관리 프로그램을 제공합니다.

## 프로젝트 선택

### VMX on WPI — WPILib 2026

VMX2026 확장 프로그램으로 일반 WPILib 프로젝트를 VMX-pi 배포 대상으로 연결합니다. C++와 Java 로봇 프로젝트를 지원합니다. 로봇은 64비트 Ubuntu, NetworkManager 기반 네트워크, `robot_manager` 서비스를 사용합니다.

[WPILib 2026 프로젝트 설정 및 배포 →](vmxonwpi/guides/vmx-pi/software-install.md)

### W4Studica — WPILib 2027

W4Studica 문서는 별도의 2027 베타 프로젝트와 자체 확장 프로그램·HAL·작업 흐름을 다룹니다. 해당 안내는 VMX on WPI 2026에 적용되지 않습니다.

[W4Studica 문서 열기 →](W4Studica/index.md)
