---
title: VMX-Pi 네트워크
---

VMX-Pi는 Wi-Fi 핫스팟, 공유기 Wi-Fi, 유선 연결로 PC와 통신할 수 있습니다.

## 기본 연결

설치 기본값은 `WorldSkills-1234` 핫스팟입니다. 비밀번호는 `password`이고, 2.4 GHz 채널 6을 사용합니다. 팀 번호에 따라 로봇의 주소가 정해집니다. 예를 들어 팀 번호가 1234이면 `10.12.34.2`입니다.

| 연결 방식 | VMX-Pi 주소 | PC 설정 |
|---|---|---|
| Wi-Fi 핫스팟 | 팀 번호가 1234이면 `10.12.34.2` | `WorldSkills-1234`에 연결 |
| 유선 연결 | `172.22.11.2` | PC의 유선 IPv4를 DHCP(자동)로 설정 |
| 공유기 Wi-Fi | 공유기가 할당한 주소 | VMX-Pi와 PC를 같은 공유기에 연결 |

핫스팟이나 랜선으로 연결한 뒤 SSH로 접속할 수 있습니다. VMX-Pi 사용자 이름은 `ubuntu`입니다.

```sh
ssh ubuntu@10.12.34.2
ssh ubuntu@172.22.11.2
```

## 핫스팟 이름과 비밀번호 변경

`setupHotspot`은 Wi-Fi 이름 뒤에 팀 번호를 붙입니다. 예를 들어 다음 명령은 `W4-1234` 핫스팟을 만들고 로봇 주소를 `10.12.34.2`로 설정합니다.

```sh
sudo setupHotspot W4 1234 2.4 RobotWifi2027
```

마지막 인수는 Wi-Fi 비밀번호입니다. WPA2 비밀번호는 8~63자여야 합니다. 위 예시 비밀번호를 그대로 사용하지 말고 본인만 아는 값으로 바꾸세요. 비밀번호를 생략하면 기본값 `password`가 적용됩니다.

`2.4` 또는 `5`로 Wi-Fi 대역을 선택할 수 있습니다. 채널을 지정하지 않으면 사용 가능한 기본 채널을 고릅니다. 5 GHz 채널을 사용할 수 없는 지역 설정이라면 2.4 GHz를 사용하세요.

## 공유기 Wi-Fi로 전환

공유기에 연결하면 핫스팟은 꺼집니다. SSID와 비밀번호를 넣어 전환합니다.

```sh
sudo toggleNetMode wifi HomeRouter RouterPassword2027
```

다시 로봇의 핫스팟을 사용하려면 다음 명령을 실행합니다.

```sh
sudo toggleNetMode ap
```

유선 연결은 별도로 설정하지 않는 한 `172.22.11.2` 주소로 계속 사용할 수 있습니다. 네트워크 모드를 바꾸면 현재 SSH 연결이 끊길 수 있으니, 전환이 끝난 뒤 새 주소로 다시 접속하세요.
